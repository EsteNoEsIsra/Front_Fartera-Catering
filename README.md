# Fartera-Catering 

Welcome to the repository for **Fartera-Catering**, a responsive and interactive website for a restaurant and catering service.

##  About the Project

Fartera-Catering is a front-end web application designed to showcase a restaurant's menu, catering services, and contact information. It provides an elegant user interface and a seamless browsing experience across all devices.

## Features

*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
*   **Interactive Menu:** Dynamic and easy-to-navigate display of food and catering options.
*   **Image Gallery:** High-quality image grid showcasing delicious dishes and past catering events.
*   **Contact & Booking:** Easy-to-use form for reservations and catering inquiries.
*   **Modern UI:** Clean, intuitive, and visually appealing layout tailored for the hospitality industry.

## Built With

This project was built using standard web technologies without external heavy frameworks:

*   **HTML5** - For the semantic structure of the web pages.
*   **CSS3** - For styling, responsive layouts (Flexbox/Grid), and smooth animations.
*   **JavaScript (Vanilla JS)** - For interactivity, DOM manipulation, and form validation.

##  Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Safari, Edge) to view the project. No backend setup is required.

### Installation

1. Clone the repo:
   ```sh
   git clone https://github.com/EsteNoEsIsra/Front_Fartera-Catering
   ```
2. Navigate to the project directory:
   ```sh
   cd Fartera-Catering
   ```
3. Open `index.html` in your web browser, or use an extension like VSCode Live Server for a better development experience.
